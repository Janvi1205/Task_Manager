<b>Task Manager<b>
A lightweight, responsive task management web application with a modern UI and dark mode support.

Features

✅ Simple Task Management: Add and delete tasks easily<br>
🌓 Dark Mode Support: Toggle between light and dark themes<br>
📱 Fully Responsive: Works on all devices from mobile to desktop<br>
💾 Local Storage: Remembers your theme preference<br>
🚀 No Dependencies: Pure HTML, CSS, and JavaScript<br>

Live Demo
Check out the live demo: https://janvi1205.github.io/Task_Manager<br>

Usage

Add a Task: Type your task in the input field and click "Add task" button<br>
Delete a Task: Click the "Delete" button next to any task to remove it<br>
Toggle Theme: Click the moon/sun icon in the top right to switch between light and dark modes<br>

Technologies Used
HTML5<br>
CSS3 (with CSS variables for theming)<br>
JavaScript<br>
